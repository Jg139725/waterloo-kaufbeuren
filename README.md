# Waterloo Kaufbeuren – Website-Entwurf V2

Schwarz-roter GitHub-Pages-Entwurf für Waterloo Kaufbeuren. Die drei Visuals im Ordner `assets` sind eigens für den Entwurf erstellte Platzhalter und können später durch Originalfotos des Betriebs ersetzt werden.

## Upload
Alle Dateien und den Ordner `assets` direkt ins Root des GitHub-Repositories hochladen. Vorhandene `index.html` und `style.css` ersetzen.
